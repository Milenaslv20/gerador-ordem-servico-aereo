# Gerador de Ordem de Servico Aéreo

Sistema web para gerar Ordens de Serviço e documentos SEGVOO em formato `.docx` a partir dos dados da aeronave, motor, hélice e serviços necessários para realização.

## Acesso web

[ Link ](https://gerador-ordem-servico-aereo.onrender.com/)
O sistema se enconta disponível para acesso público via web link sendo armazenado no Render.


## Tecnologias

- Node.js
- Express
- Docxtemplater
- PizZip
- HTML, CSS e JavaScript

## Execução local

Instale as dependências:

```bash
npm install
```

Inicie o servidor:

```bash
npm start
```

Depois acesse:

```text
http://localhost:3000
```
